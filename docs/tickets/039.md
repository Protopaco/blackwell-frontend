# [039] Remove redundant "Client Summary" button from Pay Period header

**Board status:** Backlog

## Background

`PayPeriodHeader.tsx` renders a `NavButton` labeled "Client Summary" (`src/pages/PayPeriod/PayPeriodLayout/PayPeriodHeader.tsx:22`) that links to `/client/{clientId}` — the exact same destination as the `ClientSummaryButton` already present in the app bar (`src/components/Header/ClientSummaryButton/ClientSummaryButton.tsx`, rendered via `Header.tsx:13`). The two buttons are functionally redundant; the Pay Period page one just adds an extra, differently-styled way to reach the same page.

## Scope

Remove the "Client Summary" `NavButton` from `PayPeriodHeader.tsx`. Leave the app bar's `ClientSummaryButton` as the single entry point to the client summary page.

Out of scope: the similar `NavButton` "Client Summary" pattern in `ClientManagementPage.tsx:36` is not part of this ticket.
