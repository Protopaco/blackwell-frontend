# [065] EmployeeActivityRatesFields — repeatable row list

**Board status:** Backlog
**Part of:** [063] Employee Activity Rates in Employee Dialog (Epic)
**Depends on:** [064]

## Background

See [063] for the full design. Directly modeled on `FundingAllocationFields` (`src/components/ActivitiesManagement/ActivityDialog/FundingAllocationFields.tsx`) — same shape, different fields.

## Scope

- New `EmployeeActivityRatesFields` component, rendered in `CreateEmployeeDialog`/`EditEmployeeDialog` below the identity/Salaried fields
- Each row: Activity dropdown (filtered to active activities, excluding already-selected ones — same dedup pattern as the funding-source dropdown), `payRateType` dropdown (hourly/flatrate/salary), `payRate` field (disabled when `payRateType` is `salary`), `holidayPayRate` field, delete icon button
- "Add activity" button appends a blank row; no row cap
- Fully staged in local dialog state (not immediate-write) — submits as part of the parent Employee `POST`/`PUT` payload when the dialog's Save button is clicked
- Validation: each row needs an activity and a `payRateType`; `payRate` required unless `payRateType` is `salary`; no duplicate activity across rows
