# [033] FundingSources tab

**Board status:** Backlog
**Part of epic:** [030] Per-Pay-Period Configuration UI
**Depends on:** [028] Edit Activities & Funding Sources within a pay period (backend)

## Background

New tab on the Pay Period page for the period's FundingSources snapshot. Unlike [032]'s Activities tab, this is **read-only** — there is no update endpoint for a FundingSource within a pay period snapshot at all, and once [036] ships, adding/removing FundingSources on a period is fully managed by the application (auto-added alongside the Activities that need them) rather than a user-driven action. A FundingSource only matters once an Activity references it, so there's no case where a user needs to add or remove one directly.

## Scope

- New tab, new page under `client/:clientId/payPeriod/:payPeriodId`, same routing pattern as [032].
- Read-only list of the pay period's FundingSources snapshot (from `payPeriodApi.v1GetPayPeriodConfig`) — no add, remove, or edit actions.
