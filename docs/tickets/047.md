# [047] BUG - Employee timesheet generated after pay period closed doesn't show up in pay period summary

**Board status:** Backlog
**Reported:** 2026-07-27
**Resolved:** 2026-08-11

## Background

Reported: you can generate an employee timesheet after the pay period is closed, but it doesn't show up in the pay period summary.

Possible cause (unconfirmed): may be a timing issue with Google not updating the "last modified" field quickly enough.

## Resolution

Confirmed not a bug — a Google Sheets API propagation delay. The timesheet was created correctly; the summary just took a couple of minutes to reflect it. No code fix needed.

## Scope

None — resolved as expected API latency, not a defect.
