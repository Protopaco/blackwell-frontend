# [076] Tooltips on status chips explaining what each status means

**Board status:** Backlog

## Background

**This is `blackwell-frontend` work.**

There are two status-chip components in the app, each rendering one of a fixed set of status values as
a colored `Chip` with no further explanation:

- `EmployeeTimesheetStatusChip` (`src/components/Shared/EmployeeTimesheetStatusChip/`) — NotGenerated,
  Generated, Submitted, Approved, Complete
- `PayPeriodStatusChip` (`src/components/Shared/PayPeriodStatusChip/`) — Pending, Open, Processed,
  Allocated, Closed

A new or less-frequent user has no way to tell what each status actually means (e.g. what's the
practical difference between "Submitted" and "Approved," or "Processed" and "Allocated") without asking
someone or digging through the app's behavior.

## Scope

Not fleshed out yet — needs a design pass before estimating. At minimum:
- Add a `Tooltip` (MUI) wrapping each chip with a brief, plain-language explanation of that status
- Write the explanation copy for all 10 status values across both chip components
- Decide whether the tooltip text lives inline next to each color mapping (matching the existing
  `Record<Enum, ChipProps['color']>` pattern) or in a separate copy file
