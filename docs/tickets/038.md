# [038] Standardize page background color to match Client Summary

**Board status:** Backlog

## Background

`ClientSummary.tsx` wraps its content in `<Box sx={{ backgroundColor: blue[50] }}>`. Other pages don't apply this background, so the app looks visually inconsistent between the Client Summary page and everything else.

## Scope

Apply the same `blue[50]` background color across all pages, matching Client Summary.
