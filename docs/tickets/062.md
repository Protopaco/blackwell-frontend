# [062] Edit Client dialog on ClientSummary

**Board status:** Backlog
**Part of:** [059] Client Management Workflow (Epic)

## Background

See [059]. Editing client identity/status happens from the page where a client is already in view, rather than a separate route.

## Scope

- "Edit" button on `ClientSummary.tsx`
- Dialog (matching existing edit-dialog patterns, e.g. `EditEmployeeDialog`) for `clientName`, `clientCode`, `status` (Active/Inactive)
- No delete — deactivation via `status` is the only removal path
- Submit wired to `PUT /api/v1/client/{clientId}` via the generated `clientApi`
