# [036] Auto-add required FundingSources when adding an Activity to a pay period (backend)

**Board status:** Backlog
**Part of epic:** [030] Per-Pay-Period Configuration UI
**Depends on:** [028] Edit Activities & Funding Sources within a pay period (backend)

## Background

`addActivityToPayPeriod.ts` currently throws `UnprocessableError` (`validateActivityFundingSources.ts`) if the Activity being added references any FundingSource not already present in the pay period's FundingSource snapshot — forcing the caller to add each missing FundingSource individually first, then add the Activity, as two-plus separate user-facing steps with an extra point of failure.

## Scope

Change `addActivityToPayPeriod.ts` so that instead of validating-and-throwing on missing FundingSources, it auto-copies any of the Activity's referenced FundingSources that aren't yet in the pay period's snapshot into it, as part of the same call — atomically, in one request. Adding an Activity should never fail solely because a FundingSource it needs hasn't been manually added to the period yet.

This removes the need for a standalone "add FundingSource to a pay period" user flow entirely — see [033], revised to a read-only FundingSources tab now that this covers the only case a FundingSource needed to be added.
