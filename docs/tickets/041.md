# [041] In-app Instructions / FAQ page

**Board status:** Backlog

## Background

Client-facing help (e.g. "how do I add a client," "how do I run payroll") is being handled today via a Google Doc shared alongside the live demo link, to avoid taking on a new UI surface to maintain right now. Worth revisiting once the app is more stable — an in-app page keeps instructions discoverable right where a confused user already is, instead of a separate doc they have to remember exists and find the link to.

## Scope

TBD — a lightweight static page (not a full wiki: no search, no versioning, no editing UI) covering a handful of common step-by-step tasks. Content, page location/nav entry, and exact task list to be discussed before implementation.
