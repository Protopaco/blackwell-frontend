# [073] Manage active/inactive clients (Clients list page)

**Board status:** Backlog

## Background

**This is `blackwell-frontend` work** (may need a small backend read endpoint depending on design — TBD).

There's currently no way to browse clients by status. `ClientSelector` in the header shows all clients in a flat `Autocomplete` regardless of `status`, and there's no page listing clients at all — only the per-client `ClientSummary` once one is selected.

This came up while discussing whether client selection belongs in the header at all (see the shelved "Clients Selector → Client Manager → Pay Period Manager" drill-down architecture idea from the [061]/[062] work — parked for now, not being acted on). This ticket is narrower and doesn't require that bigger rework: a dedicated Clients list page, most likely reusing the existing list-page pattern (`ManagementListPanel`/table, like `EmployeesManagement`'s "Show inactive" toggle) with an Active/Inactive filter.

## Scope

Not fleshed out yet — needs a design pass before estimating. At minimum:
- A Clients list page/table with an Active/Inactive filter (mirroring `EmployeesManagement`'s "Show inactive" switch)
- Decide whether this replaces, supplements, or is independent of the header `ClientSelector`
