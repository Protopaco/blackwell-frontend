# [068] Remove old Activity payRate/flatRateAmount fields from frontend

**Board status:** Ready
**Part of:** [048] Expand EmployeeActivityRates (Epic) — frontend counterpart to backend [052]
**Depends on:** [052] (blackwell-backend — payRate/flatRateAmount removed from Activity)

## Background

**This is `blackwell-frontend` work.**

Backend [052] removed `payRate`/`flatRateAmount` from the `Activity` model — pay rates are now per-employee via `EmployeeActivityRates` ([063]-[065]), not per-activity. The frontend was never updated to match, so regenerating the API client from the current backend (`npm run api:gen`) breaks the build: several files still reference `Activity.payRate`, `Activity.flatRateAmount`, and the now-gone `ActivityPayRateEnum`.

## Scope

- `src/components/ActivitiesManagement/activityDisplay.ts` — delete entirely (`isFlatPayRate`/`payRateLabels` have no field left to key off of)
- `src/components/ActivitiesManagement/ActivityDialog/ActivityDetailsFields.tsx` — remove the "Pay rate" dropdown and conditional "Flat rate amount" field; keep activity name, track separately, payroll category
- `src/components/ActivitiesManagement/ActivityDialog/ActivityDialog.tsx` — remove `payRate`/`flatRateAmount` state, validation, and submit payload fields
- `src/components/ActivitiesManagement/ActivitiesTable/ActivitiesTable.tsx` — remove "Pay Rate"/"Flat Rate Amount" columns and the `payRate` sort key
- `src/components/PayPeriodDashboard/ActivitiesCard/ActivitiesCard.tsx` — remove "Pay Rate"/"Flat Rate Amount" columns and the `payRate` sort key
- `src/components/PayPeriodDashboard/ActivitiesCard/ActivityRow/ActivityRow.tsx` — remove "Pay Rate"/"Flat Rate Amount" cells
