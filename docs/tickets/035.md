# [035] Rename "timesheetStatus" page/route identifier to "Employees"

**Board status:** Backlog

## Background

The Employees tab on the Pay Period page (`PayPeriodLayout.tsx`) still uses `"timesheetStatus"` as its internal route/tab-value identifier, left over from before [031] renamed its display label to "Employees". The label and the identifier are now out of sync, which is confusing to read.

This is scoped narrowly to the page/route identity only — not the separate (and still accurate) `EmployeeTimesheetStatus` domain concept (the per-employee status enum: NotGenerated/Generated/Submitted/etc., and everything named after it: `EmployeeTimesheetStatusCard`/`Row`/`Chip`, `timesheetApi.v1GetTimesheetStatus`, `TIMESHEET_STATUS_PROGRESSION`). Those describe what state an employee's timesheet is in and are unrelated to this rename.

## Scope

- `src/pages/PayPeriod/PayPeriodLayout/PayPeriodLayout.tsx`: rename the `Tab`'s `value="timesheetStatus"` to something like `value="employees"`, and update the `tabValue` derivation logic and the `navigate(nextValue === 'timesheetStatus' ? basePath : ...)` check to match.
- Update `router.tsx`'s index route comment/structure if needed for clarity (index route path itself doesn't change — it's still the default `/payPeriod/:payPeriodId` path).
- Grep for any other reference to the `'timesheetStatus'` tab-value string (as opposed to the `EmployeeTimesheetStatus` domain naming) and update it.
- Confirm final identifier name with the user before implementing (e.g. `employees` vs. something else) — not yet decided.
