# [064] Employee dialog — remove old pay-rate fields, add Salaried toggle

**Board status:** Backlog
**Part of:** [063] Employee Activity Rates in Employee Dialog (Epic)

## Background

`hourlyPayRate1`, `hourlyPayRate2`, `holidayPayRate` are being removed from Employee entirely (see [051]) — no back-compat needed, pre-launch. `salaryAmount` is new. See [063] for the toggle UX decision.

## Scope

- Remove the old rate fields from `EmployeePayRateFields` (or remove the component entirely if nothing else uses it)
- Add a "Salaried" toggle next to the existing "Active" status toggle
- When "Salaried" is on, show a `salaryAmount` number field; when off, the field is hidden and `salaryAmount` submits as unset/0
- Wire into both `CreateEmployeeDialog`/`useCreateEmployeeForm` and `EditEmployeeDialog`/its form hook
