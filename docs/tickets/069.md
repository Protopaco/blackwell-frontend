# [069] Remove old Employee hourlyPayRate/holidayPayRate fields from frontend

**Part of:** [048] Expand EmployeeActivityRates (Epic) — frontend counterpart to backend [051]

## Background

**This is `blackwell-frontend` work.**

Backend [051] removed `hourlyPayRate1`, `hourlyPayRate2`, and `holidayPayRate` from the `Employee` model — pay rates now live per-(employee, activity) via `EmployeeActivityRates`. `EmployeesTable.tsx` was never updated and still reads these fields, which broke once the API client was regenerated against the current backend.

## Scope

- `src/components/EmployeesManagement/EmployeesTable/EmployeesTable.tsx` — remove the "Pay Rates" column (Rate 1/Rate 2/Holiday) and its `payRates` sort key. Not replacing it with a new activityRates summary column here — that's a display decision for whoever picks up surfacing `activityRates`/`salaryAmount` in the table, out of scope for this cleanup ticket.
